# Changelog

## 0.1.0-alpha.20 — 2026-08-31

### Foundation Convergence closure
- Completed the Foundation Convergence implementation series across Semantic Fabric, Truth/Evidence authority, core decomposition, Benchmark Lab, Learning Plane, Execution Fabric, Observatory projection boundaries, active certification, resource accounting and portable scale-memory evidence.
- Preserved the alpha.19 public protocol/MCP compatibility and source-authority/recovery/policy invariants while adding exact-commit active certification for the repository-defined 12 exit criteria.
- Hardened release identity so the release-admission manifest command is machine-bound to `VERSION`; a stale release command now fails the same gate as stale package/runtime/plugin/current-document identity.
- Synchronized package, runtime, plugin, current status/limitations, README and release-admission artifact names to `0.1.0-alpha.20` / `0.1.0a20`.

### Measurement and claim boundaries
- Cross-platform process peak-RSS evidence carries explicit method/scope provenance, fresh child-process scale cycles and normalized measurement-environment fingerprints; mixed environments and incomparable SLO joins fail closed.
- CI scale evidence remains descriptive/non-gating without a separately curated production baseline, and matching environment fingerprints are comparison scope rather than proof of identical physical hardware/load.
- Provider-reported tool/token/compute usage remains governed evidence, not independently verified billing truth; this release does not claim AGI, universal correctness, universal language precision, universal hostile-code microVM isolation or same-model performance superiority without controlled external evidence.
