# Capability Diagnosis — 0.1.0-alpha.17

This is an admission ledger, not a marketing checklist.

| Capability | Status | Mechanism | Boundary |
|---|---|---|---|
| Canonical source + derived Semantic Twin | Implemented | source authority + rebuildable compiler view | remote production authority incomplete |
| Semantic/Effect/Dataflow/Runtime world stack | Implemented bounded | revisioned static/runtime facts + provenance | static possibility and runtime correlation are not causality |
| Counterfactual Worlds | Implemented bounded | overlay fork/apply/evaluate/verify/promote | verifier quality remains oracle-dependent |
| Sparse Context VM I/O | Implemented | authoritative range reads + accounting | remote range API quality provider-dependent |
| Cognitive resilience | Implemented alpha.13 | loop/thrash/epistemic pressure + world health | observes operations, never hidden CoT |
| Executive Trajectory | **Implemented alpha.14** | durable hash-chain phase/event history | orchestration record, not internal reasoning |
| Executive phase enforcement | **Implemented alpha.14** | control-step transition validator + recovery/reflection gate | auxiliary milestone events do not advance control phase |
| Executive hard budgets / stop | **Implemented alpha.14 bounded** | max steps/failures/switches + failed/abandoned stop | token/tool/time/compute meters not yet native |
| Hierarchical milestone planning | **Implemented alpha.14** | dependency DAG + postconditions + priority | postconditions are not formal proofs |
| Revision-bound verification | **Implemented alpha.14** | known verifier artifacts + freshness checks | external artifacts without provenance remain weaker |
| Semantic completion gate | **Implemented alpha.14 bounded** | milestones + verifier + revision + contradiction + invalidation + invariant checks | cannot prove universal correctness |
| Strategy switching | **Implemented alpha.14 bounded** | symptom classifier -> structural recovery family + anti-cosmetic fallback | heuristic, not learned optimal policy |

| Tamper-evident trajectory history | **Implemented alpha.14 local** | SHA-256 per-trajectory hash chain | no external notarization/consensus |
| Agent-scoped cognition | Implemented bounded | agent sessions + private state/notifications | not every world record is agent-private |
| Policy + leases + transaction ownership | Implemented local | policy engine + SQLite atomic ownership | not distributed consensus |

| Observatory | Implemented read-only | SQLite query-only read model + HTTP/SSE | bounded projection; browser is not authority |
| AI Operator viewport mirror | **Implemented alpha.16, hardened alpha.17** | loopback raw-CDP screencast + versioned ephemeral frame ring + read-only Observatory endpoint | browser-frame mirror, not OS remote desktop; falls back explicitly |

| Hostile-code production sandbox | Missing universal guarantee | provider-dependent containment | top production security boundary |
| Distributed multi-agent consensus | Missing | — | local leases/rebase are not consensus |
| AGI capability | Not claimed | — | Habitat adopts control principles, not an AGI label |

## Admission interpretation
Alpha.16 can support claims about explicit long-horizon executive state, postcondition-oriented milestones, revision-bound verifier admission, failure preservation, structural anti-stagnation recovery and fail-closed completion over Habitat-visible state. It cannot support claims of hidden-cognition inspection, universal program proof, calibrated probabilistic reasoning, hostile-code safety on all hosts, distributed correctness, or AGI/model-quality superiority.
